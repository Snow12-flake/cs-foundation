# Flask REST API

## Description
A simple REST API built using Flask. The API provides endpoints to return
the current time, a random joke, and echo JSON data sent by the user.

This project introduces backend development and RESTful APIs.

## Features
- GET current time
- GET random joke
- POST JSON echo response

## API Endpoints
- `GET /time` – Returns the current server time
- `GET /joke` – Returns a random joke
- `POST /echo` – Echoes back JSON sent in the request body

## Technologies Used
- Python
- Flask

## How to Run
```bash
python app.py
