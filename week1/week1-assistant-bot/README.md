# Personal Assistant Bot

## Description
This project is a simple command-line personal assistant built with Python.
It interacts with the user through text input and responds to basic commands.

This project focuses on learning Python fundamentals and user interaction
through the terminal.

## Features
- Responds to greetings
- Handles simple user commands
- Runs entirely in the terminal

## Technologies Used
- Python

## How to Run
```bash
python assistant.py
