# Guess the Number Game

## Description
A command-line game where the computer generates a random number and the user
tries to guess it. The program provides feedback until the correct number
is guessed.

This project strengthens logic, loops, and problem-solving skills.

## Features
- Random number generation
- User input validation
- Loop until the correct guess
- Feedback for high/low guesses

## Technologies Used
- Python

## How to Run
```bash
python guess.py
