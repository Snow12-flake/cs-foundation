# Probability Simulator

## Description
Monte Carlo simulation engine for probability experiments. Runs large number of trials 
to approximate real-world probabilities through statistical sampling.

## Features
- Coin flip simulations (fair/biased coins)
- Dice roll experiments (single/multi-die)
- Confidence intervals calculation
- Statistical analysis: mean, variance, std dev
- Configurable trial counts (10k+)

## Technologies Used
- Python random, statistics modules

## How to Run
```bash
cd week4/probability_simulator
python probability_sim.py
# 10000 coin flips → ~50% heads
# 6-sided dice → uniform distribution
