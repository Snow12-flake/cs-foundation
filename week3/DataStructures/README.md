# Data Structures Implementations

## Description
Custom implementations of fundamental data structures from scratch. No built-in collections used.

## Features
- Stack: push/pop/peek (LIFO)
- Queue: enqueue/dequeue (FIFO)
- LinkedList: append/display traversal
- HashMap: set/get with chaining collisions  
- BST: recursive insert (left < root < right)

## Technologies Used
- Python classes and OOP

## How to Run
```bash
cd week3/DataStructures
python stack.py      # push(1,2,3) → pop()=3
python queue.py      # enqueue(1,2) → dequeue()=1
python linkedlist.py # 1→2→3→None
