# Custom Data Structures Library

## Description
Implementations of fundamental data structures: Stack, Queue, LinkedList, HashMap, and Binary Search Tree.  
Week 3 Project 5 from CS Foundations course.

## Features
- Stack: push(), pop(), peek() - LIFO
- Queue: enqueue(), dequeue() - FIFO  
- LinkedList: insert(), delete(), print_list()
- HashMap: insert(), search() - chaining collisions
- BST: insert(), search(), inorder() traversal

## Technologies Used
- Python

## How to Run
```bash
cd week3/project5_data_structures
python stack.py        # Test stack operations
python queue.py        # Test queue operations
python linkedlist.py   # Test linked list
python hashmap.py      # Test hash map collisions
python bst.py          # Test tree operations
