# Mini Shell Project

## Description
Lightweight Unix shell clone handling basic filesystem commands through Python's os/subprocess.

## Features
- pwd: print working directory
- ls [dir]: list files (recursive support)
- cd [dir]: change directory (handles ..)
- mkdir [dir]: create directories
- rm [file]: delete files
- exit: quit shell

## Technologies Used
- os module: filesystem operations
- subprocess: external command execution

## How to Run
```bash
python mini_shell.py
$ pwd
$ mkdir test_folder
$ cd test_folder
$ ls
$ exit
